# 文博检索词扩展规则

## 一、先规范化，再扩展

保留用户原词，并生成三层词：

1. **严格词**：简繁转换、常见异体字、标点空格与“年制/製”等不改变语义的规范化。
2. **等价词**：确定的别称、全称/简称、外文转写或机构规范名。
3. **相关词**：上下位词、跨期编目、旧称、学术争议称谓、常伴随工艺。只进入相关查询。

不要把第三层伪装成同义词。

## 二、字段选择

| 用户线索 | 首选字段 | 可补充字段 | 注意 |
|---|---|---|---|
| 名称、作品名 | `title` | `descriptors` | 标题过长时提取核心名词 |
| 作者、工匠、制作方 | `creator` | `descriptors` | “传某某”保留“传” |
| 朝代、年号、世纪 | `dynasty` | `descriptors` | 跨期词放相关组 |
| 窑口、产地窑系 | `kiln` | `region` 不可直接查时用 `descriptors` | 窑系与具体窑址不等同 |
| 材质、载体 | `material` | `descriptors` | “瓷”与“陶”不可互换 |
| 工艺、技法 | `technique` | `descriptors` | 组合工艺可拆分补查 |
| 釉色、颜色 | `glaze` | `descriptors` | 相近色名只作相关 |
| 纹饰、题材 | `motif` | `descriptors` | 图像题材与装饰纹样要区分 |
| 底款、铭文、题识 | `inscription` | `descriptors` | 款识不等于实物年代 |
| 器型、口足结构 | `detailed_form` | `title`、`descriptors` | 核心器类可先入 `title` |

## 三、专业扩展

### 时代

- 年号优先保留精确写法：`乾隆`、`清乾隆`、`乾隆时期`。精确写法用于严格组，数据库常见写法用于相关组。
- 跨期编目分别查询，不把范围拆成确定年代：`宋至元`、`宋元`、`宋金`、`元末明初`、`明清`。
- “仿某朝”“某朝款”“某朝风格”必须保留限定词。`清仿成化`不能严格归入`明成化`。
- 世纪换算只作相关搜索，除非用户明确接受近似范围。

### 款识与铭文

- 分开检索原文、规范写法和省略“年制”的短式，如：`大清乾隆年制`、`乾隆年制`、`乾隆款`。
- `寄托款`、`仿款`、`后加款`、`花押款`、`堂名款`是判断限定，不可删掉。
- OCR 缺字用少量可解释变体；不要穷举猜字。
- 发现款识只证明器物带有该文字，不自动证明制作年代、官窑属性或真伪。

### 窑口与窑系

- 具体窑址、窑系、文献称谓分层处理。例如“龙泉窑”与“龙泉窑系”相关但不完全等同。
- “官窑”既可能指制度属性，也可能指宋代窑口称谓。结合朝代和器物语境，不单独扩展成所有御窑。
- 南宋官窑示例：

  - 严格：`dynasty=南宋, kiln=官窑`
  - 相关：`宋 + 官窑`、`宋至元 + 官窑`、`宋元 + 官窑`、`宋金 + 官窑`
  - 研究型补充：`修内司官窑`、`郊坛下官窑`、`老虎洞窑`

后四类是编目或研究补充，不代表都能被严格归为南宋官窑。

### 工艺

- 先查数据库常用规范词，再查可解释的组合词。
- 不把相邻工艺合并：`斗彩`≠`五彩`，`青花`≠`青花釉里红`，`刻花`≠`划花`，`贴花`≠`模印`。
- 工艺可能嵌在题名或叙词中；专字段无结果时才补查 `descriptors`。

### 釉色与颜色

- 保留“釉”字与去“釉”形式作为规范变体，如 `粉青釉` / `粉青`。
- `天青`、`粉青`、`梅子青`、`豆青`、`灰青`只作为相关色名，不互作严格同义词。
- `开片`通常是釉面特征，不要默认当作釉色；可用 `descriptors` 或组合相关查询。

### 器型

- 同时识别核心器类与细部结构：如“葵口折腹圈足洗”拆为 `洗`、`葵口`、`折腹`、`圈足`。
- 核心器类可进入 `title` 或 `descriptors`，口、腹、足等结构进入 `detailed_form`。
- 用现代用途词搜索古代器型时，将用途词放相关组，避免先验替换。

## 四、图片线索的置信度

- **高**：清晰可见的器类、可辨文字、明显材料、明确装饰技法。
- **中**：常见但非唯一的釉色、纹饰、口足结构、装裱形制。
- **低**：仅凭色温判断釉色、仅凭照片风格判断年代/窑口、无法排除后仿的款识。

严格查询只使用高置信线索和用户明确条件；中低置信线索用于相关查询及补拍建议。

## 五、放宽顺序

按顺序每次改变一项：

1. 规范字形或数据库常用写法。
2. 删除最低置信的辅助字段。
3. 用确定的上位词替换一个字段。
4. 使用跨期、窑系、相邻釉色或相关工艺词。
5. 最后才使用 `descriptors` 的宽泛关键词。

保留每个查询的标签，以便解释某条藏品为何被列为相关。
